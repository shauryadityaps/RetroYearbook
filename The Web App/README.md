# Retro Yearbook - Web Application (PWA)

This directory is reserved for the **Retro Yearbook Web Application & Progressive Web App (PWA)**.

## Architecture Overview
- **Target Audience**: iOS (Safari / Add to Home Screen), Desktop, and Mobile Web users.
- **Backend & Database**: Shared Supabase instance (`https://vqahvognmtqsojeoxacs.supabase.co`).
- **Features Planned**:
  - Retro leather album shelf & polaroid viewer.
  - On-spot camera capture (`<input type="file" accept="image/*" capture="environment">`) & gallery upload.
  - HTML5 Canvas amber date stamp engine (`'YY MM DD`).
  - Fullscreen nostalgic slideshow with acoustic soundtrack.
  - Client-side PDF Scrapbook exporter and video reel generation.
  - Real-time collaboration with the native Android App via 6-digit invite codes.
